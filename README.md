# LightKey

**Making Law Accessible.** A GlassCase™ initiative.

LightKey breaks legal processes into colour-coded steps you can follow. Built for everyone — especially people who process information differently. This repository contains the source for [lightkey.org](https://lightkey.org).

## What's here

- `/pathways/` — Legal pathway pages (Commonwealth FOI is the Alpha 0.1 prototype)
- `/position/` — Position papers
- `/legal/` — Use & Privacy
- `index.html` — Homepage

## Status

Alpha. Wording, structure and visual system are open to reviewer feedback before v1.0. Feedback: research@glasscase.org.
